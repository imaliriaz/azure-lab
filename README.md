# Azure Lab

Hands-on Azure infrastructure and security work, built and documented in public.

I'm an infrastructure and security professional — 11 years running Windows Server,
Active Directory, networking and disaster recovery, and two years building and owning
an ISO/IEC 27001 ISMS for a regulated insurer. This repository is where I extend that
same control set into Azure, in code rather than in documents.

**Certifications:** CISM · CEH · MCSA
**In progress:** AZ-104 → AZ-500 → Terraform Associate

## Roadmap

- [ ] Terraform foundations — resource groups, networking, storage
- [ ] Hybrid identity — Active Directory to Entra ID, conditional access, PIM
- [ ] Hardened landing zone — segmentation, NSGs, private endpoints, Key Vault
- [ ] Backup and disaster recovery, implemented as code
- [ ] ISO 27001 Annex A and DORA controls as Azure Policy, with automated evidence collection

Each build has its own folder with the code, an architecture note, and what I'd do
differently next time.
